# 学习笔记

这里放掘金/CSDN 文章的 Markdown 草稿。发布后不要删除草稿，把链接登记到下方表格。

## 命名规则

- 格式：`YYYY-MM-DD-topic.md`
- 示例：`2026-10-28-httpx-first-request.md`
- 一篇笔记只解决一个具体问题

## 写作要求

- 先写遇到的问题，再写尝试过程，最后写结论
- 代码必须来自自己跑通的项目
- 至少保留一个真实报错或踩坑点
- 不要整篇复制教程或让 AI 代写
- 发布前检查是否泄露 Cookie、Token、手机号等敏感信息
