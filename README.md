# 🐍 Python Learning Journal (Python 长期学习日志)

## 👨‍💻 关于这个仓库

我是 **coderJ**，一名拥有 Java / Vue 全栈背景的开发者。建立这个仓库，是为了记录我系统性掌握 Python 生态的全过程。

**为什么建这个项目？**
Python 是 AI 时代的基础设施。这里不仅记录了我从基础语法到进阶特性的学习笔记，更沉淀了我在自动化脚本、FastAPI 后端开发以及 AI Agent 领域的实战代码。

**核心目标**：不追求速成，追求**体系化**和**工程化**。用时间换空间，打造自己的第二技术护城河。
