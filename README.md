## 👨‍💻 关于我 & 这个仓库

我是 **coderJ**（掘金/全网同名），一名拥有 Java / Vue 全栈背景的开发者。目前正全面拥抱 Python 生态，致力于向 AI Agent 与多模态应用方向进阶。

**为什么建这个仓库？**
这里是我的 Python 技术修炼场。不仅记录了从基础语法到进阶特性的系统学习轨迹，更沉淀了自动化脚本、FastAPI 后端开发以及 AI Agent 探索的实战代码。

**核心原则**：
1. **长期主义**：用表格记录每一次学习，拒绝三分钟热度。
2. **工程思维**：严格遵循代码规范（Type Hints, Ruff），坚持用项目驱动学习。
3. **输出倒逼输入**：持续输出代码与笔记，让学习成果可视化。
